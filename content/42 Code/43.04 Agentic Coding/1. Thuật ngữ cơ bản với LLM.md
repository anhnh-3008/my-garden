- LLM - mô hình ngôn ngữ lớn
- Token - đơn vị tính độ dài dữ liệu xử lý của LLM
- Promt - câu lệnh giao tiếp với model
- Context - ngữ cảnh được truyền vào model, tính cả những dữ liệu được training + dữ liệu người dùng gửi trong promt và lịch sử conversations.
- Context window - thuật ngữ thể hiện model có thể xử lý tối đa lượng thông tin trong 1 thời điểm, đo bằng token. Các mô hình cũ như chatgpt3 - 4k tokens, hay các model mới lên đến 200k-1m tokens
- Context window đủ lớn, cho phép model có thể:
	- Duy trì sự mạch lạc: đối với những tài liệu lớn
	- Tăng độ chính xác
	- Hiểu sâu
- AI Agent: chương trình phần mềm - tự chủ nhận thức - lập kết hoạch - hành động => đạt được mục tiêu.
	- Kiến trúc:
		- LLM - bộ não
		- Tools - chân tay
		- Bộ nhớ
- MCP - Model Context Protocol
	- giao thức - đề xuất bởi Anthropic(cuối 2024)
	- tiêu chuẩn cung cấp Context cho Model hiệu quả.
	- giúp tạo ra phản hồi tốt hơn bằng cách lấy được Context cần thiết từ hệ thống ngoài.
- MCP Server: cầu nối các AI Agents kết nối ra bên ngoài để lấy thông tin cần thiết.
