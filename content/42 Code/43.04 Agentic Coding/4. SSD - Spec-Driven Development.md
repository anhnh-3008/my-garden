# 🌿 What?
- Phát triển phần mềm hướng spec làm chuẩn.
- Spec là source of truth, ưu tiên là spec chuẩn chỉ, rõ ràng, thống nhất với tất cả thành viên và đặc biệt là AI, sau đó mới thực hiện implement dự án.

# 🌿 How?
Không có tiêu chuẩn chung, mỗi dự án sẽ có flow tiếp cận khác nhau.
- Flow(dựa theo tư tưởng chung):
	- Writting Spec
	- Planning
	- Breaking Tasks
	- Implement
