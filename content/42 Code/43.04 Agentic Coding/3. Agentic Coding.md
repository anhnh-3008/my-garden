# 🌿 What?
- AIDD - AI Driven Development - phương pháp phát triển mà AI tham gia và hầu hết các bước - từ làm tài liệu -> gen code -> kiểm thử. Lập trình viên chuyển vai trò từ người viết code sang người hướng dẫn và giám sát AI.
- Agentic Coding - là phong cách lập trình với sự hỗ trợ của AI Agent
	- Thay vì cách truyền thống là con người code chính, AI support thì AI Agent sẽ hoạt động tự chủ cao, lên plan, suy nghĩ và thực thi. Chỉ cần rất ít sự can thiệp yếu tố con người.
- Spec-Driven Development - phương pháp phát triển dựa trên đặc tả - tập trung làm specifications thật chi tiết và đầy đủ trước, sau đó code sẽ được AI sinh ra dựa trên spec.
	- Hạn chế vibe coding
# 🌿 Why?
- Thông nhất spec - toàn team - AI - chung knowleadge về dự án
- Tách biệt ý tưởng và công nghệ
- Có tổ chức, nhất quán, dễ mở rộng
- Code chất lượng hơn, đúng với yêu cầu hơn.

# 🌿 How?
- Đề cao intent-driven development - spec phải định nghĩa rõ What? trước, sau đó mới đến How?
- Tập trung xây dựng spec, tài liệu thật chi tiết, chuẩn quy tắc(tổ chức, công nghệ sử dụng)
- Thực hiện multi-step refinement, thay vì tạo code theo kiểu one-shot promt.
- Phụ thuộc mạnh mẽ vào khả năng của các mô hình AI tối tân trong việc đọc hiểu và diễn giải Spec một cách chính xác.
